# 時間計算機

**開始 + 間隔 = 結束。** 改任何一個，另外兩個跟著算好；時區、月曆、各種寫法都是同兩個時刻的不同讀法，一個畫面看完，永遠不用捲動。

線上版：<https://anong0u0.github.io/time-calculator/>

## 能做什麼

- **一個輸入框吃所有格式**：`2026-12-25 18:00`、`1795380034`、`+30天`、`3個月後`、`東京 15:00`、`W12`、`47m × 16`、`跨年`。先預覽會改哪一端，Enter 套用。也可以在空白處直接貼上。
- **答案方程式列**：開始、間隔、結束並排。間隔可以點一下輸入、按住數字左右拖曳，或用 `+1天`、`+30天` 等快捷；結束可以「連動」（跟著開始移動）或「固定」。
- **時區**：每一列同時顯示開始與結束在當地的時刻，下方的 24 小時條共用一條軸，● ○ 可以拖曳。
- **月曆**：ISO 週次、開始到結束的範圍、拖曳選日期，加上整年的週條。
- **讀法**：ISO 8601、Unix 秒與毫秒、UTC、RFC 2822、HTTP、SQL、Excel 序號、民國、ISO 週、第幾天，以及間隔換算成週、天、小時、分、秒與工作日。點一下就複製。
- 夏令時間（跳過與重複的時刻）、工作日（僅扣週末）、多層復原與重做、深淺色、鍵盤操作與螢幕報讀。

## 開發

需要 [Bun](https://bun.sh)。

```sh
bun install
bun run dev      # 開發伺服器
bun test         # 單元測試（時區、日曆、解析器）
bun run build    # 型別檢查並輸出到 dist/
```

推送到 `main` 後，GitHub Actions 會跑測試、建置，並把 `dist/` 發布到 `gh-pages` 分支（GitHub Pages）。

## 結構

```
src/core/      計算核心：時區換算、日曆、間隔與時長運算、文字解析（無 UI，可單獨測試）
src/state/     狀態、復原歷史、單一輸入框的解析建議
src/components 介面：方程式列、時區、月曆、讀法
tests/         bun test
```
