# 時間計算機

**開始 + 間隔 = 結束。** 改任何一個，另外兩個跟著算好；時區、月曆、各種寫法都是同兩個時刻的不同讀法，一個畫面看完，永遠不用捲動。

線上版：<https://anong0u0.github.io/time-calculator/>

## 能做什麼

- **一個輸入框吃所有格式**：`2026-12-25 18:00`、`1795380034`、`+30天`、`3個月後`、`東京 15:00`、`W12`、`47m × 16`、`跨年`。先預覽會改哪一端，Enter 套用。也可以在空白處直接貼上。
- **答案方程式列**：開始、間隔、結束印在錶面上，由一條刻度軌串起（● ─ + ─ 間隔 ─ = ─ ○），軌上是進度與現在的紅色指針。按 `+` 輸入間隔，按 `=` 切換結束是固定還是跟著開始移動。
- **時區**：每一列同時顯示開始與結束在當地的時刻與上班／下班／週末／深夜，下方的 24 小時條共用一條軸，● ○ 可以拖曳。空間夠時加上晝夜世界地圖（晨昏線、太陽直射點、各城市時間）。 點地圖會加入最近的城市（滑過時先預覽城市與當地時間），點地圖上的城市打開它的選單。
- **月曆**：ISO 週次、開始到結束的範圍、拖曳選日期，加上整年的週條。點標題可以直接打年份跳到任何年月；滾輪在月曆上換月、在週條上換年；PageUp／PageDown（加 Shift 換年）；點週次選整週。
- **時長計算機**：`2h 45m + 1:30:20 − 15m`、`3:59:59 ÷ 42.195`，逐步算式、各單位總和，算完可以設為間隔；不按就不會動到開始和結束。從間隔卡的計算機按鈕或頂端輸入框打開，螢幕夠寬時是固定的第四欄。
- **讀法**：ISO 8601、Unix 秒與毫秒、UTC、相對時間、中文、民國、ISO 週、美式週次、第幾天（含下次閏年）、RFC 2822、SQL、Excel 序號、HTTP，以及間隔換算成週、天、小時、分、秒與工作日。點一下就複製，時間戳類的可以直接改寫。 每個值都有複製圖示，能改寫的有筆；複製後該列直接顯示「已複製」。常用的格式可以釘到上面，「複製表格」把全部寫法複製成 Tab 分隔的表格。
- 夏令時間（跳過與重複的時刻）、工作日（僅扣週末）、多層復原與重做、深淺色、鍵盤操作與螢幕報讀。
- **錶面**：整個畫面是一個錶面，沒有卡片。同一對指針（● 開始、○ 結束）在不同尺度上讀：間隔的刻度軌、一天的 24 小時軸、一年的週刻度、一個月的月曆，以及各種寫法；每個尺度都用同樣的刻度、指針與紅色的「現在」。光落在主讀數上，越遠離指針的細節越安靜。
- **網址就是狀態**：開始、結束（或間隔、或「本月結束」這類期間）、時區、時區列表都同步在網址上，可以直接加入書籤或分享，例如 `?s=2026-12-24T18:00&tz=Asia/Taipei&d=3h`。開始是「現在」時不寫進網址，所以「倒數跨年」的書籤永遠倒數到下一次跨年。右上的連結按鈕複製網址；打開別人的連結時，原本存在這台裝置的設定可以一鍵復原。
- **顯示設定**：深淺色、字級密度可調（80%–116%，越緊湊一個畫面放得越多，夠寬時切成四欄）、世界地圖開關。

## 開發

需要 [Bun](https://bun.sh)。

```sh
bun install
bun run dev      # 開發伺服器
bun test         # 單元測試（時區、日曆、解析器）
bun run build    # 型別檢查並輸出到 dist/
```

推送到 `main` 後，GitHub Actions 會跑測試、建置，並直接部署到 GitHub Pages（不經過任何分支）。

## 結構

```
src/core/      計算核心：時區換算、日曆、間隔與時長運算、文字解析（無 UI，可單獨測試）
src/state/     狀態、復原歷史、單一輸入框的解析建議
src/components 介面：方程式列、時區、月曆、讀法
tests/         bun test
```
