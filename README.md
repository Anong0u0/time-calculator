# 時間計算機

**開始 + 間隔 = 結束。** 改任何一個，另外兩個跟著算好；時區、月曆、讀法與時長計算都在同一個畫面，無需捲動。

線上版：<https://anong0u0.github.io/time-calculator/>

## 功能

- **萬用輸入框**：不限格式拆解日期與時間（西元、民國、中文數字、相對日期、ISO 週、Unix 時間戳、Excel 序號、範圍 `A 到 B`、`東京 15:00`、`+30天`、`47m × 16`），即時預覽並支援空白處直接貼上。
- **規則與自訂快捷**：起點搭配移動、對齊、挑日、時刻與詞彙積木（如 `下個月底 18:00`、`明年中秋`、`開始那個月的月底`），打字與積木互通；快捷列可拖曳排序、套用與自訂詞彙。
- **方程式與刻度軌**：兩端皆可設為即時「現在」或以間隔連動（`+` 輸入、`=` 切換／拖曳方向）；刻度軌與間隔數字皆支援拖曳、滾輪與單位原地改寫。
- **時區與晝夜地圖**：多時區同步對照與共用 24 小時拖曳軸，含晝夜晨昏線世界地圖與點擊加城市。
- **月曆、年曆與農曆節氣**：月／年檢視切換、拖曳選取範圍、自算農曆與 VSOP87 24 節氣（不依賴查表）。
- **讀法與時長計算機**：16 種常用格式一鍵複製、原地改寫、拖曳排序與 TSV 匯出；獨立時長四則運算。
- **自由版面與網址狀態**：所有面板皆可單獨開關或滿版（`1`–`9`、`P`、`0`、`Y`、`F`），更動即時同步網址供書籤與分享。

## 開發

需要 [Bun](https://bun.sh)。

```sh
bun install
bun run dev      # 開發伺服器
bun test         # 單元測試
bun run lint     # ESLint 與 Prettier 檢查（bun run format 自動排版）
bun run build    # 型別檢查並輸出到 dist/
bun run e2e      # 建置並執行 Playwright 冒煙測試
```

推送到 `main` 後由 GitHub Actions 測試、建置並部署至 GitHub Pages。

## 結構

```
src/core/        純計算核心：時區、日曆、解析、規則、詞彙、農曆與節氣（無 UI）
src/state/       響應式狀態、復原歷史、版面規劃、網址同步、命令列解析
src/components/  Vue 介面元件
tests/           Bun 單元測試
e2e/             Playwright 冒煙測試
```
