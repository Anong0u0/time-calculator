# 時間計算機

**開始 + 間隔 = 結束。** 改任何一個，另外兩個跟著算好；時區、月曆、各種寫法都是同兩個時刻的不同讀法，一個畫面看完，永遠不用捲動。

線上版：<https://anong0u0.github.io/time-calculator/>

## 能做什麼

- **一個輸入框吃所有寫法**：日期不是比對固定格式，而是拆開來讀，所以 `2000/1/1/20:34`、`2000.1.1 20.34`、`20000101 2034`、`1/1/2000 8pm`、`Jan 1 2000 8:34 pm`、`二〇〇〇年一月一日晚上八點三十四分`、`民國115年11月24日`、`115/11/24`、`明天下午3點`、`下週五`、`今晚8點`、`2026-W48-2`、`第 328 天`、Excel 序號、RFC 2822 都讀得懂；日和月分不出先後時（`1/2/2026`）兩種讀法都列出來。另外還有 `1795380034`、`+30天`、`3天前`（從現在算）、範圍 `2000/1/1 到 現在`、`2026/1/1 + 30天`、`東京 15:00`、`W12`、`47m × 16`、`跨年`。先預覽會改哪一端，Enter 套用。也可以在空白處直接貼上。
- **答案方程式列**：開始、間隔、結束印在錶面上，由一條刻度軌串起（● ─ + ─ 間隔 ─ = ─ ○），軌上是進度與現在的紅色指針。按 `+` 輸入間隔，按 `=` 切換兩端是各自固定還是用間隔連在一起。
- **兩端一樣**：開始和結束都可以是「現在」（跟著時間走），所以「從 2000/1/1 到現在過了多久」直接設結束為現在就好。間隔可以從開始算出結束（結束 = 開始 + 30天），也可以在結束是現在時從結束往回算開始（開始 = 現在 − 30天，「最近 30 天」）。交換開始與結束時，誰是現在、誰被算出來也一起交換。間隔欄也可以直接打結束的日期。
- **時區**：每一列同時顯示開始與結束在當地的時刻與上班／下班／週末／深夜，下方的 24 小時條共用一條軸，● ○ 可以拖曳。空間夠時加上晝夜世界地圖（晨昏線、太陽直射點、各城市時間）。 點地圖會加入最近的城市（滑過時先預覽城市與當地時間；手指點一下先預覽，再點一下加入），點地圖上的城市打開它的選單。各列拖曳把手就能排順序；‹ › 一天一天看；拖曳時軸不會跟著跑；還沒有結束時點時區條就是設定結束；手機上拖曳時手指往外拉可以調到分鐘。
- **月曆**：ISO 週次、開始到結束的範圍，加上整年的週條。拖曳 ● 或 ○ 只移動那一端，從別的日子拖曳選一段；手機上滑動換月、長按再拖曳選一段。點標題可以直接打年份跳到任何年月；滾輪在月曆上換月、在週條上換年；PageUp／PageDown（加 Shift 換年）；點週次或週條上的一週選整週；在某天上按 S／E 設為開始／結束；下方的週次可以直接改。
- **時長計算機**：`2h 45m + 1:30:20 − 15m`、`3:59:59 ÷ 42.195`，逐步算式、各單位總和，算完可以設為間隔；不按就不會動到開始和結束。從間隔卡的計算機按鈕或頂端輸入框打開，螢幕夠寬時是固定的第四欄。
- **讀法**：ISO 8601、Unix 秒與毫秒、UTC、相對時間、中文、民國、ISO 週、美式週次、第幾天（含下次閏年）、RFC 2822、SQL、Excel 序號、HTTP，以及間隔換算成週、天、小時、分、秒與工作日。點一下就複製，每一種都可以在原地改寫回去（例如把民國年、ISO 週或「3 天後」改掉）。拖曳每列的把手排順序；「全部寫法」列出每一種，拖到線上面就會顯示在面板上，排序可以復原。「複製表格」把全部寫法複製成 Tab 分隔的表格。
- 間隔欄接受 `1.5天`、`2h30`、`三天`、`1年 + 3天`、`in 3 days`、ISO 的 `P1M7DT12H`；拖曳數字可以一路拖過 0。
- 夏令時間（跳過與重複的時刻）、工作日（僅扣週末）、多層復原與重做、深淺色、鍵盤操作與螢幕報讀。日期欄聚焦不會改任何東西，Esc 放回原本的值。
- **錶面**：整個畫面是一個錶面，沒有卡片。同一對指針（● 開始、○ 結束）在不同尺度上讀：間隔的刻度軌、一天的 24 小時軸、一年的週刻度、一個月的月曆，以及各種寫法；每個尺度都用同樣的刻度、指針與紅色的「現在」。光落在主讀數上，越遠離指針的細節越安靜。
- **網址就是狀態**：開始、結束（或間隔、或「本月結束」這類期間）、時區、時區列表改動後會同步到網址上（打開頁面時不會自己寫上去），可以直接加入書籤或分享，例如 `?s=2026-12-24T18:00&tz=Asia/Taipei&d=3h`。開始是「現在」時不寫進網址，所以「倒數跨年」的書籤永遠倒數到下一次跨年；結束是現在寫成 `e=now`，`?e=now&ds=30d` 永遠是最近 30 天。右上的連結按鈕複製網址；打開別人的連結時，原本存在這台裝置的設定可以一鍵復原。
- **顯示設定**：深淺色、字級密度可調（80%–116%，越緊湊一個畫面放得越多，夠寬時切成四欄）、世界地圖開關。

## 開發

需要 [Bun](https://bun.sh)。

```sh
bun install
bun run dev      # 開發伺服器
bun test         # 單元測試（時區、日曆、解析器）
bun run build    # 型別檢查並輸出到 dist/
```

推送到 `main` 後，GitHub Actions 會跑測試、建置，並直接部署到 GitHub Pages（不經過任何分支）。

## 結構

```
src/core/      計算核心：時區換算、日曆、間隔與時長運算、文字解析（無 UI，可單獨測試）
src/state/     狀態、復原歷史、單一輸入框的解析建議
src/components 介面：方程式列、時區、月曆、讀法
tests/         bun test
```
